# Tether icons

Redrawn as SVG from the supplied `tether-app-icon.png` / `tether-logo.png` (same shapes and colors:
blue `#2f5bff`, ink `#111318`, white laptop outline 16/384 thick).

- `icon-mac.svg` → `icon.png` (1024², macOS icon grid: 824² body on the canvas) → the Mac app icon
- `icon-ios.svg` → `public/icons/apple-touch-icon.png` (180²) and `public/icons/icon-512.png` (full square; iOS rounds it)
- `public/icons/icon.svg` → favicon (+ `favicon-32.png`); `public/icons/mark.svg` → the mark next to "Tether" on light pages
